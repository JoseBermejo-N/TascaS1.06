# 🐘 Advanced PHP & Object-Oriented Programming
Welcome to my PHP learning repository! This space is dedicated to collecting practical exercises, code challenges, and advanced OOP concepts (Superglobals, Magic Methods, Enums, and Traits) that I develop as I progress through my training by ITAcademy.

## 🚀 Development Environment
- **PHP** (Version 8.2.12) 
- **Local Server:** XAMPP (Apache)
- **Editor:** Visual Studio Code

## 📂 Repository Structure
The project is organized by difficulty levels for easy navigation:

- **nivel1/** : Core advanced concepts including forms, session handling, magic constants, and overriding magic methods.
  - `ejercicio1/` : HTML Form and PHP processor using superglobals and sessions.
  - `ejercicio2/` : Implementation of native magic constants.
  - `ejercicio3/` : Custom logic by overriding magic methods.
- **nivel2/** : Strict typing and code reuse structures.
  - `ejercicio1/` : Didactic resource class strictly typed using Enums.
  - `ejercicio2/` : Car class implementing horizontal code reuse via Traits.

## 🛠️ How to Run This Project
Due to the use of sessions and forms in **Nivell 1 (Exercici 1)**, this project requires a local web server environment like **XAMPP**. Follow these steps to run the exercises:

1. **Clone this repository inside XAMPP:** 
   Navigate to your XAMPP installation folder, open the `htdocs` directory, and clone the repository there:
   ```bash
   cd C:/xampp/htdocs (Windows) o /Applications/XAMPP/xamppfiles/htdocs (macOS)
   git clone  https://github.com/JoseBermejo-N/TascaS1.06.git
   ```
2. **Start the local server:** Open the XAMPP Control Panel and start the **Apache** module.
3. **Run the files in your browser:** 
   Open your preferred web browser and navigate to the project URL:
   `http://localhost/XAMPP/htdocs/tascaS1.06/nivel1/ejercicio1/index.php`
   From there, you can browse through the folders and test each exercise interactively.


To the rest of the exercises:

1. **Clone this repository:** https://github.com/JoseBermejo-N/TascaS1.06.git
2. **Open the folder in your editor:** Open Visual Studio Code, go to File -> Open Folder, and select the cloned repository folder.
3. **Run the files:**
   - Open any `.php` file.
   - Right-click inside the editor and select "Run code".
